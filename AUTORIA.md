# Autoría y procedencia

Selección de prácticas académicas de estructuras de datos entregadas por Jacobo Martínez Martín. Las interfaces y el planteamiento proceden del contexto docente; los nombres de terceros se omiten por privacidad.

Se publican una cola enlazada aplicada a pedidos y un inventario basado en un árbol binario de búsqueda. No se incluye la implementación AVL incompleta. Los originales se mantienen fuera de este repositorio; las correcciones necesarias para compilar y comprobar los ejemplos se identifican en el historial.

No se atribuye una licencia nueva a plantillas o partes de autoría no confirmada.
